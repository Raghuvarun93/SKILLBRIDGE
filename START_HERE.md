## 🚀 5-Step Deployment (Takes ~15 Minutes Total)

### Step 1: Create GitHub Repository (2 minutes)

1. Open https://github.com/new in your browser
2. Fill in:
   - Repository name: `skillbridge` (or `skillbridge-hackdevengers`)
   - Description: "AI-powered career gap analyzer - HackDevengers 1.0"
   - Visibility: **PUBLIC** ⚠️ (must be public for submission)
   - DO NOT check "Initialize with README"
3. Click "Create repository"
4. **COPY the repository URL** shown on the page
   - It looks like: `https://github.com/YOUR_USERNAME/skillbridge.git`

---

### Step 2: Push Code to GitHub (1 minute)

Open your terminal in this folder (`skillbridge`) and run these commands **one by one**:

```bash
git remote add origin YOUR_GITHUB_URL_HERE
```
(Replace `YOUR_GITHUB_URL_HERE` with the URL you copied)

```bash
git branch -M main
```

```bash
git push -u origin main
```

✅ Your code is now on GitHub!

---

### Step 3: Deploy to Vercel (3-5 minutes)

1. Go to https://vercel.com/signup
2. Click "Continue with GitHub"
3. Authorize Vercel to access your GitHub
4. After login, click "Add New..." button (top right)
5. Select "Project"
6. Find your `skillbridge` repository in the list
7. Click "Import"
8. **Do NOT change any settings** (Vercel auto-detects everything)
9. Click **"Deploy"**
10. Wait 2-3 minutes for the build to complete
11. **COPY YOUR LIVE URL!**
    - It looks like: `https://skillbridge-abc123.vercel.app`

✅ Your site is now live!

---

## ⚠️ Troubleshooting

### Git push fails?
```bash
git remote remove origin
git remote add origin YOUR_CORRECT_URL
git push -u origin main
```

### Vercel build fails?
- Make sure your GitHub repo is PUBLIC
- Try re-importing the project in Vercel
- Check the build logs for errors

### Site doesn't load?
- Wait 30 seconds and refresh
- Clear browser cache
- Try incognito/private mode

### Need more help?
- Check `DEPLOYMENT.md` for detailed instructions
- Check `COMMANDS.md` for all commands
- Read error messages carefully
